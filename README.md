# SmartHealRunverve

React Native app built with **Expo SDK 54** (React Native 0.81, React 19.1).

## Prerequisites

- **Node.js >= 20.19.4** (SDK 54 requirement — Node 22 recommended)
- npm 10+
- Expo CLI (`npx expo --version`)

## Setup

1. Switch to Node 22: `nvm use 22.18.0` (if using nvm-windows)
2. Install dependencies: `npm install`
3. Start Metro: `npm run start`
4. Launch a target:
   - Android: press `a` in Expo CLI or `npm run android`
   - iOS (macOS only): press `i` or `npm run ios`
   - Web: press `w` or `npm run web`

## Notes

- App entry: `App.tsx`
- Config: `app.json`
- TypeScript: `tsconfig.json`
- New Architecture enabled by default
